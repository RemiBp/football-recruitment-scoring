# Data and methods

Data: [Football Data from Transfermarkt](https://www.kaggle.com/datasets/davidcariboo/player-scores), published by David Caribou, sourced from Transfermarkt. Publisher repository: [dcaribou/transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets). The publisher repository declares [CC0 1.0](https://github.com/dcaribou/transfermarkt-datasets/blob/master/LICENSE). The derived table contains tabular data only; no player images, logos or site assets are redistributed.

Snapshot: 6 July 2026 according to the publisher. SHA-256 checksums in `data/manifest.json` identify the actual downloaded files; a future `--download` may retrieve a different snapshot.

Foundation comparator: [TabICL](https://github.com/soda-inria/tabicl), checkpoint `tabicl-classifier-v2-20260212.ckpt`. Code and model licensing remain governed by their upstream sources. No weights are committed to this repository.

The employment-use framing references [EU AI Act Annex III, paragraph 4(a)](https://ai-act-service-desk.ec.europa.eu/en/ai-act/annex-3) and [French recruitment discrimination guidance](https://travail-emploi.gouv.fr/discriminations-lembauche-de-quoi-parle-t). Exact classification depends on intended use and applicable conditions. This project is an academic evaluation, not an operational recruitment system.

No paper establishing a Brazilian valuation premium or African undervaluation has yet been verified for this submission. Those claims should not be presented as established evidence. The analysis tests descriptive associations rather than manufacturing an expected conclusion.
